## 4. 新进度 token（效果全确认）

- **Mysticism**：终局每持有 1 个神话 token 和 1 个献祭 token 得 2 分。
- **Poliorcetics**：你每将冲突棋子向前移动 1 格，对手失去 1 金。
- **Engineering**：可以 1 金建造任何带白色连锁符号的卡，无需拥有对应前置（不触发 Urbanism）。
