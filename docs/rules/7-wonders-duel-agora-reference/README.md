# 7 Wonders Duel: Agora component reference

## What is included

- `photos/01-chambers-score-laurels.jpg`: all six Chamber victory-point laurels are visible (1, 1, 2, 2, 3, 3), plus the four military tokens.
- `photos/02-senator-cards-public-photo-4-types.jpg`: four representative Senator fronts (three Politicians and one Conspirator). This is not a 13-card spread.
- `photos/03-conspiracy-cards-public-photo-6-of-16.jpg`: six named Conspiracy cards with their main effects and icons. This is not the complete 16-card set.
- `photos/04-decree-and-military-tokens.jpg`: four military tokens are clear; Decree tokens are present but stacked/overlapping.
- `official-rules-en.pdf`: official English rulebook.
- `official-rules-pages/`: 220 dpi renders of the component overview and complete symbol-description pages. Pages 14-19 give the authoritative effect/icon mapping when a complete public flat-lay is unavailable.
