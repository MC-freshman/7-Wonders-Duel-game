# 七大奇迹对决发布记录

## v0.1.4（2026-10-09）

Windows 可玩包仍需 Node.js 18+，解压后双击 `启动游戏.exe`，无需 `npm install`。
[下载发布附件](https://github.com/MC-freshman/7-Wonders-Duel-game/releases/tag/v0.1.4)，操作见 [使用说明](../使用说明.md)。

### 本版变化

- Agora 使用 25 / 25 / 23 格扩展牌阵，按时代移除 3 张基础卡后加入参议员；修正密谋累计取回移除卡的范围。
- Astarte 圣库金币计入建造可负担判断，避免有钱可付却没有合法建造动作。
- AI 全难度对未知牌进行确定化采样；浏览器 Web Worker 和服务器 worker_threads 在后台计算。
- 对联机奇迹材料牌、密谋和未公开神格日志字段进一步裁剪；完整回放信息仅在终局提供。
- 动作比较改为结构比较，补充 WebSocket 缓冲与房间上限、重连清理、弃牌法令收益展示。
- 发布包同时包含前端 AI Worker 和 `dist-server/aiWorkerNode.mjs`。

### 本次验证

- `check`、参议院供给边界 + 150 局 soak、Astarte 专项、25 项渲染冒烟：通过。
- 基础 / 万神殿 / Agora / 合体：各 40 局，共 160 局，无死锁和不变量违规。
- 双人逐帧回放：基础 362 帧、万神殿 475 帧、Agora 533 帧；Solo 四形态共 12 局、1026 帧：通过。
- 源码联机：四形态各 3 局，共 12 局，状态一致、无私密信息泄漏、非法行动被拒。
- 正式产物联机：3/3 局通过，HTTP 首页与当前 `dist/index.html` 完全一致；断线 AI 托管 3/3 局通过，日志确认 worker 线程启用。
- TypeScript、Vite 前端、esbuild 双入口服务器构建：通过。
- 前端主包 gzip 104.31 KB、CSS gzip 4.67 KB；额外前端 AI Worker 84.17 KB（未压缩）。
