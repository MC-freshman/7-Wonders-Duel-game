# 真机回归清单（iOS Safari / Android Chrome）

> 目的：补上「桌面 Chromium 模拟视口」验证之外的**真机**缺口。
> 前置条件：本机已 `npm run build` + `npm run server:start`（或打包 exe），
> 手机/平板与电脑在同一 WiFi，用「局域网访问」地址打开。
> 执行人只需按表勾选，所有判定标准都写成「看得见/点得动/无报错」这类可观察事实。

## 0. 准备

| 项 | 说明 | ☑ |
|---|---|---|
| 设备 A | iPhone（Safari 15+），建议真机而非模拟器 | ☐ |
| 设备 B | Android 手机或平板（Chrome 最新） | ☐ |
| 可选 | iPad Safari（验证平板断点 ≥768） | ☐ |
| 服务器 | 电脑上 `node dist-server/server.mjs`（默认 8080），打印出局域网地址 | ☐ |
| 控制台 | 每台设备 Safari/Chrome 的远程调试或 `window.onerror` 弹窗都别忽略 | ☐ |

## 5. 回归脚本（可选，自动化部分）

电脑端可复用 `scripts/browser/e2eClickFlow.cjs`（puppeteer-core + 本机 Chrome，`npm run e2e:click`）做半自动检查
（`layoutCheck.js` / `playHotseat.js` / `onlineStep.js`），真机以本清单人工项为准。

## 6. 通过标准

1. 以上「必须」项全部 ☑；带“可选项”标签的项不计入门槛。
2. 全程无未捕获 JS 错误（每台设备控制台为空）。
3. 若有任一失败：记录设备型号 / 浏览器版本 / 复现步骤，回到对应里程碑修。
